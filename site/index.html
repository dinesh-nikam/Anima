HOW THE SYSTEM RUNS

A six-stage telemetry rail,
from OAuth to live artifact.

  1. 01

    Authenticate

    GitHub OAuth handshake. Tokens sealed with AES-256-GCM in an encrypted vault — never written to disk in the clear.

  2. 02

    Synchronize

    Six failure-isolated stages ingest profile, repos, languages, contributions, activity and statistics with quota-aware backoff.

  3. 03

    Compute

    Streak derivation, weekend velocity, calendar heatmaps, and an achievement rule engine across five trophy tiers.

  4. 04

    Compose

    Drag-and-drop sections compile to real markdown through a dual-provider payload system with live health checks.

  5. 05

    Animate

    35 procedural shaders render at 60 fps in a pixel-grid exact engine, then quantize to GIF, APNG or MP4.

  6. 06

    Publish

    SHA-verified diff review, upstream collision detection, direct commit to you/you, atomic rollback.
